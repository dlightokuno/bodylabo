# D/LIGHT BODY LABO — 会員ページ

会員の方が、困ったときに自分で開いて読むためのページです。
公式サイト（dlightgym.com）とは別のサイトとして運用します。

- 合言葉：`Dlight`（大文字小文字は区別しません。変更方法は下記）
- 検索には出ません（`noindex` ＋ `robots.txt` ＋ サーバー側のヘッダー）

---

## 中身

```
01〜11-*.md     記事の原本。直すのはここ
build.py        原本から site/ を作り直す。合言葉もここで設定
serve.py        手元で表示を確認する用
src/            CSSとJSの元ファイル
site/           公開されるファイル一式（自動生成。直接さわらない）
```

**原本は .md のほうです。** `site/` の中身は毎回作り直されるので、
HTMLを直接編集しても次のビルドで消えます。

---

## 記事を直したい

1. `01-体重が2週間動かないとき.md` などを編集する
2. 作り直す

   ```
   python3 build.py
   ```

3. 手元で確認する

   ```
   python3 serve.py
   ```

   → http://localhost:4322

4. 問題なければ push する（Netlifyが自動で公開します）

---

## 記事の書き方

起承転結の四段で書きます。見出しの文言は自由ですが、**順番と数は変えない**でください。

```markdown
---
slug: mukumi                    ← URLになる（英数字）
title: 脚のむくみ
keywords: むくみ 靴がきつい …    ← 検索用の言い換え語。ひらがなも入れる
category: 不調・姿勢             ← ダイエット / 不調・姿勢 / 睡眠
video: null                     ← 動画があればYouTubeのID
---

# 脚のむくみ

## 結論：〇〇です          ← 起。開いて3秒で答えが分かる一行
## なぜ〇〇なのか          ← 承。仕組みの説明
## 〇〇は逆効果です        ← 転。読者の思い込みを、承を根拠に折る
## やること                ← 結。行動で終わる

**1. 見出し**
本文。

**2. 見出し**
本文。

> 受診の目安など、注意書きがあればここに。
```

`keywords` は目次の検索に使われます。漢字・ひらがな・言い換えを並べておくと、
会員がどう打っても記事にたどり着けます（例：「痩せない」「やせない」「止まった」）。

---

## 動画を足したい

1. YouTube に**限定公開**でアップロードする
2. URL の `v=` のあとの文字列（動画ID）を控える
3. 原稿の `video:` に書く

   ```yaml
   video: dQw4w9WgXcQ
   ```

4. `python3 build.py`

記事の結論の下に自動で埋め込まれます。関連動画は出ない設定です。

---

## 合言葉を変えたい

`build.py` の上のほうにある

```python
PASSWORD = "Dlight"
```

を書き換えて `python3 build.py`。大文字・小文字と前後の空白は無視して照合します。
ページには合言葉そのものではなく、そこから作った文字列だけが入ります。

**変えたら、会員への再周知が必要です。** 保存済みの端末でも、次から入力を求められます。

---

## LINEのリッチメニューに入れるURL

合言葉を入力させずに開けるように、鍵をURLに付けたものを登録します。

```
https://dlight-body-labo.netlify.app/?k=Dlight
```

一度開けば端末に記憶されるので、以降はどのURLからでも入力なしで開きます。

---

## 公開のしかた（初回だけ）

1. GitHub で**プライベート**リポジトリを作る（公開リポジトリにすると合言葉も記事も誰でも読めます）
2. このフォルダを push する
3. Netlify で「Add new site → Import an existing project」からそのリポジトリを選ぶ
4. 設定は `netlify.toml` が持っているので、そのまま公開して問題ありません

以降は push するだけで自動的に反映されます。
