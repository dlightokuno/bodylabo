# D/LIGHT BODY LABO — 会員ページ

会員の方が、困ったときに自分で開いて読むためのページです。
公式サイト（dlightgym.com）とは別のサイトとして運用します。

- **無料記事は誰でも読めます。** 合言葉は要りません
- **有料記事だけ、合言葉が要ります。** 本文は暗号化してあり、合言葉がないとソースを見ても読めません
- 検索には出ません（`noindex` ＋ `robots.txt`）

---

## 中身

```
01〜83-*.md     記事の原本。直すのはここ（79本）
ネタ帳.md        次に書く候補（50本）
build.py        原本から site/ を作り直す。有料の合言葉もここで設定
covers.py       トップ画の図柄を描く（写真を置いていない記事のぶん）
serve.py        手元で表示を確認する用
publish.py      作り直して GitHub Pages に送る（これ1つで公開できます）
src/            CSSとJSの元ファイル
images/         記事のトップ画。prompts.py に絵の指示、finish.sh で変換
site/           公開されるファイル一式（自動生成。直接さわらない）
_保留/           いまは使っていない原稿
```

**原本は .md のほうです。** `site/` の中身は毎回作り直されるので、
HTMLを直接編集しても次のビルドで消えます。

---

## 記事を直したい

1. `01-体重が2週間動かないとき.md` などを編集する
2. 作り直す

   ```
   python3 build.py
   ```

3. 手元で確認する

   ```
   python3 serve.py
   ```

   http://localhost:4322 が開きます。止めるのは Control + C。

## 記事を新しく足したい

ファイル名は `番号-タイトル.md`。**番号2桁で始めてください**（この形のファイルだけが記事として読まれます）。

先頭に次の枠を書きます。

```
---
slug: englishname          ← URLになる。他と重ならない英字
title: 記事のタイトル
keywords: 検索に引っかけたい言葉を空白区切りで
category: 食事              ← 下の6つから選ぶ
paid: true                 ← 有料にするときだけ書く。無料なら行ごと消す
video: null                ← YouTubeの動画IDを書くと埋め込まれる
---
```

分野は次の6つです。ここに無い名前を書くと「食事」に入ります。

```
食事 ／ 運動 ／ 姿勢・不調 ／ 睡眠 ／ マインド ／ ゴルフ
```

**分野は、カンマで区切っていくつでも付けられます。**

```
category: 睡眠, 食事
```

こう書くと、「睡眠」のボタンでも「食事」のボタンでも出てきます。カードには両方の札が付きます。

**最初に書いた分野が「主な分野」です。** 目次のどの見出しの下に並ぶかは、これで決まります。
上の例なら、睡眠の欄に並びます。**カードが2か所に出ることはありません。**

分野そのものを増やすときは、`build.py` の `CATEGORIES` と `CATEGORY_OF` に足します。

本文は四段構成です。見出しは `##` で4つ。

```
## 結論：〜            ← 開いて3秒で分かる一行
## （仕組みの見出し）    ← なぜそうなるのか
## （勘違いの見出し）    ← 読者の思い込みを、仕組みを根拠に折る
## やること            ← **1. 〜** の形で3つ
```

`keywords` には**ひらがなの読みも入れてください。** 会員はスマホでひらがなのまま
検索することが多いので、これがないと当たりません。

### 検索について

目次の検索窓は、**タイトル・結論・keywords に加えて、本文の中も探します。**
記事の途中に一度だけ出てくる言葉でも見つかります。ひらがなで入れてもカタカナに当たります。
スペースで区切ると、その全部を含む記事に絞られます。

**メンバー限定の記事は、本文が検索対象に入りません。** 入れると合言葉なしで中身が読めてしまうためです。
タイトルと結論とキーワードでは引っかかるので、案内としては働きます。

---

## 有料記事について

`paid: true` を書いた記事は、こうなります。

- **結論の一行だけが、誰にでも見えます。** ここが売り文句になります
- それより下の本文は暗号化され、合言葉を入れたときだけ表示されます
- 目次では「メンバー限定」の札が付き、検索にも引っかかります（案内になります）
- 分野は無料記事と同じです。加えて、目次の右端の「メンバー限定」ボタンで絞り込めます。
  このボタンは入／切の切り替えで、分野の選択と**組み合わせて**使えます
- 一度合言葉を入れると、その端末では次から聞かれません

いまあるメンバー限定の記事は3本です（`51`〜`53`）。新しく書くときは、
この3本のどれかをコピーするのが早いです。

### 長い記事を書くとき

無料記事は四段構成（結論→仕組み→勘違い→やること）ですが、
**メンバー限定の記事は、この形に縛られません。** 見出しはいくつ増やしても構いません。

- `##` … 章の見出し
- `###` … 章の中の小見出し
- `|` 区切り … 表になります
- `- ` … 箇条書き
- `> ` … 注意書き（色の付いた囲み）

**`##` が5つ以上ある記事には、先頭に自動で「この記事の中身」（章の一覧）が入ります。**
長い記事でも、読みたいところに飛べます。

`## 結論：〜` の一行だけは残してください。ここが目次カードの文言になり、
**合言葉を持っていない人にも見える唯一の部分**です。

### 合言葉を変えたい

`build.py` の上のほうにある

```python
PAID_PASSWORD = "dlightgymmember"
```

を書き換えて `python3 build.py`。大文字・小文字と前後の空白は無視して照合します。

短く分かりやすい単語ほど、総当たりで割り出されやすくなります。
いまの `dlightgymmember` は15文字あるので現実的な強度はありますが、
ジムを知っている人には推測されうる並びです。強くしたい場合は、
意味のない文字を混ぜてください。

**変えたら、購入者への再周知が必要です。** 保存済みの端末でも、次から入力を求められます。

### どのくらい安全か

合言葉そのものはページに入っていません。入っているのは、そこから作られた
「戻せない印」と、暗号化された本文だけです。**合言葉を知らない人は、
ソースを見ても本文を取り出せません。**

ただし**買った人が合言葉を他人に教えれば、その人も読めます。** ここは仕組みでは防げません。
防ぐには購入者ごとに違う合言葉を発行する必要があり、いまはその形にしていません。

## トップ画（記事の見出し画像）

記事1本ごとに、上に横長の画像が入ります。目次のカードにも同じ絵が出ます。
入り方には2通りあり、**写真があれば写真が、なければ自動生成の図柄が使われます。**

### 写真を使う（いまはこちら）

`images/` に **`記事のslug.jpg`** の名前で置くだけです。build すると拾われます。

写真は ChatGPT の画像生成で作れます。ゆうだいさんのログインを使うので**追加料金はかかりません。**

```
python3 images/prompts.py                       # 指示書 images/prompts.tsv を作る
~/.claude/skills/imagegen/batch.sh images/prompts.tsv 4   # まとめて作る（1枚1分ほど）
bash images/finish.sh                           # 軽いjpgに変換して images/ に置く
python3 build.py
```

**絵を変えたい記事**は `images/prompts.py` の該当行を書き換え、
`images/_raw/その記事.png` と `images/その記事.jpg` を消してから、上をもう一度回します。
（すでにある画像は飛ばす作りなので、消さないと作り直されません）

1枚だけ作るときは:

```
~/.claude/skills/imagegen/gen.sh images/_raw/slug.png "英語で絵の説明"
```

コツは `~/.claude/skills/imagegen/SKILL.md` にまとめてあります。要点は3つです。

- **文字を入れさせない。** 生成される文字は必ず崩れます
- **主役は1つだけ。** 2つ入れると崩れます
- **物の特徴を書く。** 「体重計」だけでは伝わらず、「丸い文字盤・目盛り・赤い針」まで書いて伝わりました

### 自動生成の図柄

写真を置いていない記事は、`covers.py` が分野ごとの図柄を描きます。
食事は円、運動は積み上げた棒、姿勢は背骨、睡眠は月、マインドは広がる線、ゴルフは球の弧です。
記事名から形が決まるので、同じ記事なら毎回同じ絵になります。図柄を変えるなら `covers.py` を直します。

## 公開のしかた

**GitHub Pages で公開しています。Netlify は使っていません**（クレジットを使い切ったため）。

```
https://dlightokuno.github.io/bodylabo-site/
```

リポジトリは2つに分かれています。

```
dlightokuno/bodylabo       Private   原稿(.md)・build.py・合言葉。ここは公開されません
dlightokuno/bodylabo-site  Public    site/ の中身だけ。GitHub Pages がここを配ります
```

**合言葉の入った build.py が公開側に出ないように、分けてあります。**

公開するときは、これを実行します。

```
python3 publish.py
```

作り直してから、`site/` の中身だけを Public 側に送ります。反映は1〜2分です。
原稿の履歴を残すなら、あわせて Private 側にも `git push` してください。

Netlify の古いサイト（`dlight-body-labo.netlify.app`）はそのまま残してあります。
更新はされないので、案内するURLは上の GitHub Pages のほうを使ってください。
