# D/LIGHT BODY LABO — 会員ページ

会員の方が、困ったときに自分で開いて読むためのページです。
公式サイト（dlightgym.com）とは別のサイトとして運用します。

- **無料記事は誰でも読めます。** 合言葉は要りません
- **有料記事だけ、合言葉が要ります。** 本文は暗号化してあり、合言葉がないとソースを見ても読めません
- 検索には出ません（`noindex` ＋ `robots.txt`）

---

## 中身

```
01〜53-*.md     記事の原本。直すのはここ（49本）
ネタ帳.md        次に書く候補（50本）
build.py        原本から site/ を作り直す。有料の合言葉もここで設定
serve.py        手元で表示を確認する用
src/            CSSとJSの元ファイル
deploy.sh       作り直して Netlify に送る（これ1つで公開できます）
site/           公開されるファイル一式（自動生成。直接さわらない）
_保留/           いまは使っていない原稿
```

**原本は .md のほうです。** `site/` の中身は毎回作り直されるので、
HTMLを直接編集しても次のビルドで消えます。

---

## 記事を直したい

1. `01-体重が2週間動かないとき.md` などを編集する
2. 作り直す

   ```
   python3 build.py
   ```

3. 手元で確認する

   ```
   python3 serve.py
   ```

   http://localhost:4322 が開きます。止めるのは Control + C。

## 記事を新しく足したい

ファイル名は `番号-タイトル.md`。**番号2桁で始めてください**（この形のファイルだけが記事として読まれます）。

先頭に次の枠を書きます。

```
---
slug: englishname          ← URLになる。他と重ならない英字
title: 記事のタイトル
keywords: 検索に引っかけたい言葉を空白区切りで
category: 食事              ← 下の6つから選ぶ
paid: true                 ← 有料にするときだけ書く。無料なら行ごと消す
video: null                ← YouTubeの動画IDを書くと埋め込まれる
---
```

分野は次の6つです。ここに無い名前を書くと「食事」に入ります。

```
食事 ／ 運動 ／ 姿勢・不調 ／ 睡眠 ／ マインド ／ ゴルフ
```

分野そのものを増やすときは、`build.py` の `CATEGORIES` と `CATEGORY_OF` に足します。

本文は四段構成です。見出しは `##` で4つ。

```
## 結論：〜            ← 開いて3秒で分かる一行
## （仕組みの見出し）    ← なぜそうなるのか
## （勘違いの見出し）    ← 読者の思い込みを、仕組みを根拠に折る
## やること            ← **1. 〜** の形で3つ
```

`keywords` には**ひらがなの読みも入れてください。** 会員はスマホでひらがなのまま
検索することが多いので、これがないと当たりません。

## 有料記事について

`paid: true` を書いた記事は、こうなります。

- **結論の一行だけが、誰にでも見えます。** ここが売り文句になります
- それより下の本文は暗号化され、合言葉を入れたときだけ表示されます
- 目次では「メンバー限定」の札が付き、検索にも引っかかります（案内になります）
- 分野は無料記事と同じです。加えて、目次の右端の「メンバー限定」ボタンで絞り込めます。
  このボタンは入／切の切り替えで、分野の選択と**組み合わせて**使えます
- 一度合言葉を入れると、その端末では次から聞かれません

いまあるメンバー限定の記事は3本です（`51`〜`53`）。新しく書くときは、
この3本のどれかをコピーするのが早いです。

### 長い記事を書くとき

無料記事は四段構成（結論→仕組み→勘違い→やること）ですが、
**メンバー限定の記事は、この形に縛られません。** 見出しはいくつ増やしても構いません。

- `##` … 章の見出し
- `###` … 章の中の小見出し
- `|` 区切り … 表になります
- `- ` … 箇条書き
- `> ` … 注意書き（色の付いた囲み）

**`##` が5つ以上ある記事には、先頭に自動で「この記事の中身」（章の一覧）が入ります。**
長い記事でも、読みたいところに飛べます。

`## 結論：〜` の一行だけは残してください。ここが目次カードの文言になり、
**合言葉を持っていない人にも見える唯一の部分**です。

### 合言葉を変えたい

`build.py` の上のほうにある

```python
PAID_PASSWORD = "dlightgymmember"
```

を書き換えて `python3 build.py`。大文字・小文字と前後の空白は無視して照合します。

短く分かりやすい単語ほど、総当たりで割り出されやすくなります。
いまの `dlightgymmember` は15文字あるので現実的な強度はありますが、
ジムを知っている人には推測されうる並びです。強くしたい場合は、
意味のない文字を混ぜてください。

**変えたら、購入者への再周知が必要です。** 保存済みの端末でも、次から入力を求められます。

### どのくらい安全か

合言葉そのものはページに入っていません。入っているのは、そこから作られた
「戻せない印」と、暗号化された本文だけです。**合言葉を知らない人は、
ソースを見ても本文を取り出せません。**

ただし**買った人が合言葉を他人に教えれば、その人も読めます。** ここは仕組みでは防げません。
防ぐには購入者ごとに違う合言葉を発行する必要があり、いまはその形にしていません。

## 公開のしかた

GitHub（`dlightokuno/bodylabo`、Private）に置き、Netlify が公開します。

```
https://dlight-body-labo.netlify.app/
```

**リポジトリと Netlify は繋いでいません。** 繋ぐと push のたびに Netlify が
組み立て作業をして、無料枠のビルド時間を使うためです。

公開するときは、これを実行します。

```
./deploy.sh
```

作り直してから、出来上がったファイルだけを送ります。Netlify に組み立てさせないので、
**ビルド時間は消費しません。**

GitHub は原稿の保管場所、Netlify は公開係、という分担です。
`git push` しても公開されないので、公開したいときは必ず `./deploy.sh` を実行してください。
