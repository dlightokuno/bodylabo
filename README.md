# D/LIGHT BODY LABO — 会員ページ

会員の方が、困ったときに自分で開いて読むためのページです。
公式サイト（dlightgym.com）とは別のサイトとして運用します。

- **無料記事は誰でも読めます。** 合言葉は要りません
- **有料記事だけ、合言葉が要ります。** 本文は暗号化してあり、合言葉がないとソースを見ても読めません
- 検索には出ません（`noindex` ＋ `robots.txt`）

---

## 中身

```
01〜30-*.md     記事の原本。直すのはここ
ネタ帳.md        次に書く候補（50本）
build.py        原本から site/ を作り直す。有料の合言葉もここで設定
serve.py        手元で表示を確認する用
src/            CSSとJSの元ファイル
site/           公開されるファイル一式（自動生成。直接さわらない）
_保留/           いまは使っていない原稿
```

**原本は .md のほうです。** `site/` の中身は毎回作り直されるので、
HTMLを直接編集しても次のビルドで消えます。

---

## 記事を直したい

1. `01-体重が2週間動かないとき.md` などを編集する
2. 作り直す

   ```
   python3 build.py
   ```

3. 手元で確認する

   ```
   python3 serve.py
   ```

   http://localhost:4322 が開きます。止めるのは Control + C。

## 記事を新しく足したい

ファイル名は `番号-タイトル.md`。**番号2桁で始めてください**（この形のファイルだけが記事として読まれます）。

先頭に次の枠を書きます。

```
---
slug: englishname          ← URLになる。他と重ならない英字
title: 記事のタイトル
keywords: 検索に引っかけたい言葉を空白区切りで
category: ダイエット        ← ダイエット／姿勢・不調／睡眠・頭痛
paid: true                 ← 有料にするときだけ書く。無料なら行ごと消す
video: null                ← YouTubeの動画IDを書くと埋め込まれる
---
```

本文は四段構成です。見出しは `##` で4つ。

```
## 結論：〜            ← 開いて3秒で分かる一行
## （仕組みの見出し）    ← なぜそうなるのか
## （勘違いの見出し）    ← 読者の思い込みを、仕組みを根拠に折る
## やること            ← **1. 〜** の形で3つ
```

`keywords` には**ひらがなの読みも入れてください。** 会員はスマホでひらがなのまま
検索することが多いので、これがないと当たりません。

## 有料記事について

`paid: true` を書いた記事は、こうなります。

- **結論の一行だけが、誰にでも見えます。** ここが売り文句になります
- それより下の本文は暗号化され、合言葉を入れたときだけ表示されます
- 目次では「有料」の札が付き、検索にも引っかかります（買っていない人への案内になります）
- 一度合言葉を入れると、その端末では次から聞かれません

ひな形として `30-ひな形（有料記事）.md` を置いてあります。
コピーして使い、**公開前にひな形そのものは削除してください。**

### 合言葉を変えたい

`build.py` の上のほうにある

```python
PAID_PASSWORD = "labo-9x4k2m"
```

を書き換えて `python3 build.py`。大文字・小文字と前後の空白は無視して照合します。

**辞書にある単語は使わないでください。** `dlight` のような単語だと、
ページに入っている印から総当たりで割り出されます。意味のない文字列にしてください。

**変えたら、購入者への再周知が必要です。** 保存済みの端末でも、次から入力を求められます。

### どのくらい安全か

合言葉そのものはページに入っていません。入っているのは、そこから作られた
「戻せない印」と、暗号化された本文だけです。**合言葉を知らない人は、
ソースを見ても本文を取り出せません。**

ただし**買った人が合言葉を他人に教えれば、その人も読めます。** ここは仕組みでは防げません。
防ぐには購入者ごとに違う合言葉を発行する必要があり、いまはその形にしていません。

## 公開のしかた

GitHub（`dlightokuno/bodylabo`、Private）に置き、Netlify が公開します。

```
https://dlight-body-labo.netlify.app/
```

Netlify とリポジトリを繋いでいる場合は、push すれば自動で公開されます。
繋いでいない場合は、手元から上げます。

```
npx --yes netlify-cli@latest deploy --prod --dir site --no-build
```
